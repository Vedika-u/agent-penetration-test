# Agent Red-Team

A benchmarked toolkit for probing LLM-powered agents for prompt-injection and jailbreak
vulnerabilities, scoring them against public safety benchmarks, and reporting results on a
live dashboard.

This project sits at the intersection of two existing project threads — SIEM/detection work
from [Act Aware](../act-aware-benchmark) and agentic pipeline design from
[OrbitDesk](https://github.com/Vedika-u/OrbitDesk-Local-AI-Agent) — applied to the emerging
niche of AI/LLM security evaluation.
